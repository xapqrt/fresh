Frames
FPS CapCapping above your panel's Hz just burns frames for nothing. On 60Hz, only 30 really bites.
Sim Tick480 Hz is the measured old-client path. 960 Hz Turbo uses the M4's spare CPU headroom; drop back if movement timing feels wrong.
Interp Delay33ms keeps one server snapshot for the lowest enemy-render latency; 66/99ms are smoother when the connection jitters.
Compositor ProfileBench-lab for frame pacing. stock is the smooth verified ride; uncap* uncorks the old client's flags — can look worse, so test with your eyes.
In-Process GPU
Mouse Latency
High-Rate Aim Input Feeds Kirka the earliest device-rate pointer samples instead of relying only on normal mousemove batches. Keeps total movement unchanged and works independently of the 60Hz display.
Unadjusted Mouse Requests raw pointer lock without the macOS acceleration curve, like an aim trainer. Re-click into the match after changing it; sensitivity can feel different.
Smart Modes
Performance LockPrevents macOS App Nap from parking game and network timers while another desktop is visible. The display can still sleep.
Auto Fullscreen
Thermal GuardM4 Air has no fan. CPU pinned 80%+ for ~30s mid-match? It downshifts your tick (960→480→240) and restores it after cooling.
High Refresh AutoPlug in a 120Hz+ panel and your FPS cap + tick climb with it; unplug and it drops back. Sits quiet on the built-in 60Hz.
Repeatable Benchmark
30-second capture 3s warm-up, then measures frame pacing, CPU/memory, startup timings, raw/native mouse event rates, and input age at render. Keep aiming normally during the capture.
Ready. For useful results, start this while you are in a match.

          Shortcuts:
          
- F1: JS Debugger (needs devtools open)

          
- F2: Screenshot and copy to clipboard

          
- F4: Return to https://kirka.io

          
- F5: Reload page

          
- F6: Load URL

          
- F7: Copy URL

          
- F11: Fullscreen

          
- F12 or Ctrl + Shift + I: Open Devtools

          
- Ctrl + C: Copy image preview to clipboard

          

          
- Shift + Click on a name in global chat: Open player profile

          
- Ctrl + Click on a name in global chat: Copy player Name#ID

          
- Shift + Click on a game in friends list: Copy game link

          
- Click on a clan in profile: Lookup clan
